# Glossaire

| Terme | Définition |
|---|---|
| BI-RADS / ACR | Classification de 0 à 6 de l'American College of Radiology ; 4 se subdivise en 4A, 4B, 4C |
| CC | Incidence cranio-caudale (de haut en bas) |
| MLO | Incidence oblique médio-latérale |
| Densité A-D | Densité mammaire : A (graisseux) à D (extrêmement dense) |
| Asymétrie | Différence de densité entre les deux seins ou entre deux zones |
| Distorsion architecturale | Déformation de la trame mammaire sans masse visible |
| Adénopathie | Ganglion augmenté de volume |
| Exam | Un examen = les images prises lors d'une même venue (jusqu'à 4 vues) |
| exam_id | Identifiant pseudonymisé d'un examen (aucune identité) |
| ADR | Architecture Decision Record : décision documentée |
