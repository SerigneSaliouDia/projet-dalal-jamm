# Guide d'annotation manuelle (sprint 8)

À rédiger par Saliou avec l'équipe puis relire avec un radiologue. Contenu attendu :

1. Pour chaque signe et chaque sein : `1` / `0` / vide (définitions et exemples).
2. Règles pour les cas limites (« opacité », « ganglion intramammaire », « calcification vasculaire »...).
3. BI-RADS par sein, y compris 4A/4B/4C et valeurs latéralisées.
4. Procédure de double annotation et mesure d'accord.
