# Équipe

Une fiche par personne : `prenom.md`. Elles sont créées lors de la première Pull Request de chacun
(voir `docs/onboarding.md`, partie 3).

| Personne | Fiche | Rôle de départ |
|---|---|---|
| Saliou | [saliou.md](saliou.md) | Coordination, fusion des PR, extraction des rapports |
| Manou | manou.md | Développement, outillage, images |
| Babel | babel.md | Données, validation, évaluation |

Les rôles sont une répartition de départ : n'importe qui peut échanger une tâche, en le notant dans la PR.
